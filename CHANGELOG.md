# Changelog

## 1.0.0 — 2026-09-02
- Packaged the CAP 1.0 development build as a single self-contained project.
- Native C11 runtime with lexer, expression parser, evaluator, variables, conditions, loops, functions, input/output, strings, numbers, booleans, `nothing`, comments, assignment checks, and CAP ALERT diagnostics.
- Added CLI help/version commands.
- Added language reference, architecture notes, examples, tests, and installation scripts.
- Added a repeatable test runner.
