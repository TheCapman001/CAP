# CAP Website

This is the GitHub Pages website for the CAP Programming Language.

## Files

- `index.html` - Main website
- `style.css` - Styling
- `script.js` - Interactive features
- `logo.png` - CAP logo (to be added)
- `favicon.png` - Browser tab icon (to be added)

## To Add Your Logo

1. Save your neon CAP logo as `logo.png` in this `docs` folder
2. Optionally, create a `favicon.png` for the browser tab
3. Commit and push the changes

The website will automatically display your logo in the navigation bar and throughout the site.

## Deployment

This website is automatically deployed to GitHub Pages when you push to the `gh-pages-setup` branch and merge it to your default branch.

View it at: `https://thecapman001.github.io/CAP/`
