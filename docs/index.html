Quick Start

1. Build

make

2. Run Example

./cap examples/hello.cap

3. Create File

say "Hello, World!"

4. Run Your Code

./cap myfile.cap

Example Programs

Hello World

say "Hello, World!"

Variables & Math

x = 10
y = 20
say x + y

Conditionals

x = 5
if x > 3
  say "x is greater than 3"
end

Functions

function greet(name)
  say "Hello, " + name
end

greet "World"

Loops

x = 0
while x < 5
  say x
  x = x + 1
end

User Input

name = ask "What's your name?"
say "Nice to meet you, " + name

Download & Install

Pre-built Release

Download the latest pre-built executable for your platform

Download Latest Release

Build from Source

Clone the repository and build CAP yourself

git clone https://github.com/TheCapman001/CAP.git
cd CAP
make
./install.sh

Android / Termux

Install CAP on Android using Termux

pkg install clang make unzip
./termux-install.sh

Requirements

Standard Platforms

  • C11-compatible compiler (gcc, clang, cc)
  • POSIX-like shell environment
  • Linux, macOS, BSD

Android

  • Termux installed
  • clang compiler
  • make and unzip utilities
